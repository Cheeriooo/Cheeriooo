## Selected work

**[NexusDB](https://github.com/Cheeriooo/NexusDB)**
A vector database built from scratch. HNSW and flat indexes, metadata filtering, SQLite WAL storage, and honest benchmarks. [Live demo](https://nexusdb.rakeshsawant.space)

**[PromptDistill](https://github.com/Cheeriooo/PromptDistill)**
Compresses prompts down to the tokens carrying signal, and tells you what it dropped.

**[Alphabet_Recognition_Gestures](https://github.com/Cheeriooo/Alphabet_Recognition_Gestures)**
Real-time hand tracking to character recognition. Draw a letter in the air, it reads it.

More at [github.com/Cheeriooo](https://github.com/Cheeriooo?tab=repositories).
